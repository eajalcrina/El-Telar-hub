# El Telar

Proyecto de IA para empresas de Redesign Lab. Se publica en [eltelarhub.com](https://eltelarhub.com).

## Contenido

| Carpeta | Qué hay |
|---|---|
| `eltelarhub/` | Sitio web (Next.js): hub de El Telar  |
| `docs/` | Investigación (análisis de Satia, rubros y procesos), tesis del modelo por piezas y revisión de expertos |

## Sitio

```bash
cd eltelarhub
npm install
npm run dev
```
