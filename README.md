# El Telar

Proyecto de IA para empresas de Redesign Lab. Se publica en [eltelarhub.com](https://eltelarhub.com).

## Contenido

| Carpeta | Qué hay |
|---|---|
| `eltelarhub/` | Sitio web (Next.js): hub de El Telar y propuestas a clientes en `/propuestas/` |
| `docs/` | Investigación (análisis de Satia, rubros y procesos), tesis del modelo por piezas, revisión de expertos y la propuesta para Happy Plaza |

## Sitio

```bash
cd eltelarhub
npm install
npm run dev
```

Los textos viven en `eltelarhub/data/`. Precios y fechas de la propuesta a Happy Plaza: `eltelarhub/data/propuesta-happy-plaza.ts`.
